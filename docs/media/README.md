# Media placeholders

The `.gif` files in this folder are **generated placeholders**. Replace each one with a real recording (same file name — the README picks them up automatically).

| File | What to record | Suggested take |
| --- | --- | --- |
| `demo.gif` | Hero shot for the README top | Chase camera, a drift or fast cornering with **3D Forces** arrows on, ~8–10 s |
| `debug-hud.gif` | Debug HUD in action | Pacejka Fx/Fy graphs with the live operating point sweeping the curve while accelerating and cornering, suspension graph reacting to a kerb, ~10 s |
| `force-arrows.gif` | Tire-force arrows close-up | Low camera near a wheel during launch/braking: Fx (blue), Fy (red), Fz (green) changing length, ~6 s |
| `live-tuning.gif` | Runtime tuning panel | Open **Tuning** (Ctrl frees the cursor), drag spring stiffness or swap RWD→AWD mid-drive, show the car behaviour change, ~10 s |
| `multi-car.gif` | Multi-car scenario | `MultiCarScenario` preset (Slalom Parade or Stress Test), wide shot of the fleet moving + stats overlay, ~10 s |

Recording tips: 960×540 or 1280×720, 30 fps, under ~15 MB per GIF (GitHub renders files up to 100 MB, but pages load faster when GIFs are small). [ScreenToGif](https://www.screentogif.com/) works well on Windows.
